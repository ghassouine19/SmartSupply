# SmartSupply

## Intelligent Supply Chain Data & Optimization Platform

SmartSupply is an end-to-end platform combining:

- Data Engineering
- Machine Learning
- Operations Research
- Business Intelligence

The platform aims to forecast product demand, optimize inventory
decisions and generate optimized delivery routes.

## Main Technologies

- Python
- Apache Spark
- Apache Hudi
- Apache Airflow
- MinIO
- PostgreSQL
- XGBoost / LightGBM
- MLflow
- OR-Tools
- FastAPI
- Streamlit
- Docker
